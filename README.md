# The Odin Project: Computer Science

My solutions and notes for the Computer Science section of [The Odin Project](https://www.theodinproject.com/lessons/javascript-a-very-brief-intro-to-cs) JavaScript path.

## What I Learned

- **Recursion:** exercises and projects built around solving problems by breaking them into smaller versions of themselves
- **Linked List:** a singly linked list with methods to append, prepend, insert, remove, search, and print
- **Hash Map:** a hash map (and hash set) with dynamic resizing and collision handling
- **Binary Search Trees:** a balanced BST with insertion, deletion, traversal, and rebalancing
- **Knight's Travails:** shortest-path search for a chess knight using graph traversal

## Concepts practiced

- Recursion and base cases
- Big O notation and algorithm efficiency
- Linked lists, hash maps, and trees
- Breadth-first and depth-first traversal
- Writing and testing code with no built-in data structure helpers

## Tech

- JavaScript (ES6+)
- Node.js
- Jest (for tests)
